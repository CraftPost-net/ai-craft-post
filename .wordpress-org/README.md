# WordPress.org directory assets

This directory stores the version-controlled source assets for the WordPress.org plugin page. It is excluded from release ZIP exports and copied separately to the top-level `assets/` directory of the WordPress.org SVN checkout.

Expected publication files:

- `icon-128x128.png`
- `icon-256x256.png`
- `banner-772x250.png`
- `banner-1544x500.png`
- `screenshot-1.png`
- `screenshot-2.png`
- `screenshot-3.png`
- `screenshot-4.png`

Screenshots should correspond to the numbered descriptions in `readme.txt`.
